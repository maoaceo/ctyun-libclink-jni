# 天翼云电脑 Clink / QUIC 原生多设备轮询保活控制台 (ctyun-libclink-jni)

基于天翼云官方 Linux 原生视讯串流引擎（**Clink / QUIC RFC 9000**）构建的高性能、超轻量无头多设备轮询保活中心。

---

## 🌟 核心特性与优势

1. **官方 Clink / QUIC 视讯内核串流**：
   - 绝非模拟 Web 网页端的无效 HTTP 上报，而是直接调用天翼云官方 Linux 客户端的底层视讯引擎 `clouddesktop-qml`；
   - 建立真实的媒体流连接并接收首张渲染帧（时延 ~65ms），彻底重置官方机房的 **5 分钟（游戏版）/ 10 分钟（普通版）** 断开倒计时。
2. **极轻量、超低服务器配置要求**：
   - 采用纯无头虚拟显示（`Xvfb`），内存常驻仅约 `200~300MB`，CPU 仅占个位数；
   - 无需任何笨重的桌面环境或大型虚拟机。
3. **单实例多设备轮询防冲突**：
   - 5 台甚至多台设备单实例串流排队轮询（每台保持 35 秒，完整周期仅需 3 分钟）；
   - 既防止账号被风控多开并发踢线，又避免多路视频解码压垮低配 VPS。
4. **精美 Web 控制面板**：
   - 📱 **手机扫码登录授权**：自动展示官方最新二维码与确认直链；
   - 🖥️ **设备 ID 与编码管理**：支持一键增删云电脑设备，自带防重复与独占保护；
   - 📜 **实时视讯握手与日志查看**：实时观察视讯建立、握手、延时与轮询进度。

## 🚀 快速开始与部署

### 1. 克隆代码与初始化运行环境

```bash
git clone https://github.com/maoaceo/ctyun-libclink-jni.git
cd ctyun-libclink-jni

# 运行一键初始化脚本（自动下载官方 Linux 核心库并配置依赖）
chmod +x setup.sh web_server.py
./setup.sh
```

### 2. 启动 Web 控制台服务

```bash
# 启动 Web 管理面板（默认端口 8572）
python3 web_server.py
```

后台常驻运行：
```bash
nohup python3 web_server.py > web.log 2>&1 &
```

启动后在浏览器打开 `http://你的服务器IP:8572` 即可进入管理控制面板！

---

## 📱 使用流程

1. **打开控制面板**：访问 `http://服务器IP:8572`。
2. **手机扫码授权**：在左侧“手机扫码授权”面板中，使用天翼云电脑 App 或微信扫描二维码并确认（或直接点击确认直链）。
3. **添加云电脑**：输入你的云电脑数字 ID、设备名称与编码，添加到轮询队列。
4. **自动保活**：系统将全天候自动在名下设备间平滑轮询握手，各机器永久保持在线不关机！

